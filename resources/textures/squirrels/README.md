# Initial squirrel artwork

Two static RGBA sprites generated using the built-in image generator. These are
the initial reusable assets; no animation frames or dog artwork changes are used.

- `surprised.png`: full squirrel, raised paws and surprised expression.
- `hidden_tail.png`: matching tail alone, with genuine transparency around it.

Generation prompt for `surprised.png`:

> A single friendly brown squirrel character sprite for a storybook video game, standing upright with a surprised expression and raised paws, fluffy curved tail, softly painted illustration with simple readable shapes. Full squirrel visible and centered on a transparent background, ample empty margin. No lettering or scenery.

Edit prompt for `hidden_tail.png`, using the surprised image as reference:

> Create the hiding pose asset for this same squirrel game character. Show ONLY its fluffy curved russet brown tail standing upright, with a slim base and a broad rounded curled tip, matching the fur colors and painting style of the reference. The squirrel itself is hidden: no head, ears, torso, paws or feet should appear. Center the standalone tail on a genuinely transparent canvas with a small margin. No foliage, objects, ground, shadow, lettering or border. This is a single tail-only game sprite.
