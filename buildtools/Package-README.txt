Sniff the Way - A Tail to Guide You Home

This package contains two versions of the game:

  SniffTheWay-Vulkan.exe
    The preferred renderer. Use this first if your graphics hardware supports Vulkan 1.3.

  SniffTheWay-OpenGL.exe
    The compatibility renderer. Use this if the Vulkan edition reports unsupported hardware.

Both executables use the shared resources directory. Keep the executables and resources together when moving or extracting the game.
